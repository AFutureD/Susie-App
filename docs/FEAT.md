# Susie 功能指南

Susie 的使用逻辑是三层递进：先准备 Agent（核心第一步），有了 Agent 就有可用的助手，再把助手绑定到渠道和会话。

第一次打开 Susie，按启动向导完成下面 5 步；完成后即可在 Telegram 中让本机 Agent 回复消息。

1. 准备 Agent：使用 Susie 检测到的 Codex 或 Claude CLI，安装推荐 Agent；也可以稍后在「Agent」页完成。
2. 添加 Manager Bot：在 BotFather 创建 Bot，开启 Bot Management Mode，再把 token 交给 Susie 连接。
3. 绑定 Owner：用自己的 Telegram 账号给 Manager Bot 发一条消息，然后在 Susie 中设为 Owner。
4. 创建会话 Bot：填写用户名和显示名称，由 Manager Bot 在 Telegram 中创建并接入。
5. 绑定默认助手：为新 Bot 选择默认助手，并决定它默认响应所有会话，还是只响应之后指定的会话。

完成标志：给新 Bot 发一条 Telegram 消息，Bot 能返回助手的回复。

## 日常聊天

- 私聊中直接给 Bot 发消息；群聊默认仅在提及 Bot 时响应。
- 发送 `/new` 开启新会话，发送 `/model` 查看或切换模型，发送 `/help` 查看当前可用命令。
- 在「会话」页的「会话历史」中搜索全部消息、查看回复引用，并以 Bot 身份继续发送消息；历史列表按渠道分组，可折叠。向上阅读旧消息时会保持当前位置，回到底部后继续自动跟随新消息。
- Agent 可使用 Susie 提供的能力主动发送消息、回复指定消息、查询历史和列出会话。

Telegram 频道贴文会进入会话历史，但不会触发 Bot 自己参与频道对话。

## 渠道、助手与会话路由

「渠道」页集中管理 Telegram Bot。推荐用 Manager Bot 创建和接入托管 Bot；已有普通 Bot 也可以通过 token 直接添加。渠道可随时停用、重新启用或删除。

渠道状态实时反映连接健康：网络中断或 token 冲突时显示错误原因，故障排除或网络恢复后状态自动回到运行中，无需重启应用；启动时网络不可用的渠道也会在网络恢复后自动完成启动。

添加渠道或托管 Bot 后，Susie 会立即请你为它绑定默认助手，并选择该渠道默认响应所有会话，还是只响应之后指定的会话；跳过选择时使用 default 助手且默认不响应，之后可随时在「会话」页调整。

在「助手」页使用标题右侧的「新增助手」创建助手，并管理已有助手：

- 每个助手有名称（用于界面展示）和不可更改的 ID。
- 为助手选择 Agent、默认模型、思考深度和工作目录。
- 可把助手回复额外转发到另一个会话。
- 名为「默认」的默认助手（ID 为 default）始终存在、不可删除且不可改名，是新渠道和向导的兜底选择。

「会话」页决定每个会话由谁处理、是否响应：

- 左侧按渠道分组列出会话，分组可折叠。
- 每个渠道有默认助手，以及"是否响应未列出会话"的默认开关。
- 为单个会话添加绑定即可让它被响应——助手可留空跟随渠道默认，无需调整助手；也可为它指定其他助手。
- 单个会话可以单独静音（渠道默认响应时排除个别会话）。
- 决定群聊是否必须提及 Bot，并选择是否把 Agent 的完整运行输出发送到会话。
- 群聊会显示 Bot 的 Telegram 隐私模式（Privacy Mode）状态：开启时 Bot 在群里只能收到 @ 提及、回复和命令，界面会提醒并提供 BotFather 设置教程视频，调整后可点「重新检测」立即确认生效。

渠道默认设为不响应时，只有添加了绑定的会话会触发助手；没有任何绑定的渠道不响应。例外：渠道始终响应自己的 Owner——Owner 的会话即使没有列出，也由渠道默认助手处理。

## 用户权限与审核

先在「用户」页绑定 Owner。Owner 始终拥有完整权限并被渠道始终响应，也负责在 Telegram 中处理其他用户的人工审核请求。

Manager Bot 只需要 Owner：它的卡片上只能绑定或转让 Owner，不能添加普通用户；由它创建的托管渠道会继承这个 Owner。

普通用户可按私聊或具体群聊分别设置权限：

- **直通**：消息直接交给助手。
- **自动**：先由「智能 · 自动审核」评估；通过后放行，否则转给 Owner。
- **审核**：直接交给 Owner 决定允许、拒绝或终止处理。
- **忽略**：Bot 不响应。

未登记用户和未单独设置的范围默认需要审核。没有绑定 Owner 时，需要审核的消息不会执行。

## 技能

在「技能」页查看、搜索和管理 Agent Skills：

- 全局技能可供兼容的 Agent 使用；助手技能只放在该助手的工作目录中。
- 可输入 GitHub 仓库地址，浏览其中的技能并选择安装。
- 安装时选择目标助手和 Agent，Susie 会显示对应的兼容目录。
- 可在 Finder 中打开技能目录，也可删除或覆盖已有技能。
- 「助手」页会列出该助手当前真正可读的技能。

## 定时任务

在「任务」页让指定助手按计划无人值守地执行工作，并把结果发送到一个或多个会话。

1. 选择助手，填写任务内容，或选择该助手可用的技能并补充输入。
2. 使用每 N 分钟、每小时、每天、每周、每月等预设，或保留自定义 cron 表达式。
3. 选择一个或多个私聊、群聊或频道作为发送目标。
4. 保存并等待下次执行，或点击「执行」立即运行一次。

任务可按需要发送多条消息和文件。每次运行都会记录结果、触发方式及各目标的投递状态，可在「执行历史」中查看。错过的执行时间不会补跑，同一任务运行期间不会重复启动。

## 历史、运行状态与维护

- 「智能 · 历史与进度」显示自动审核中的消息及最终结论。
- 「Agent」可检测、安装、更新和卸载本机 Agent，并提示 MCP 兼容性。
- 「日志」可自动刷新全部日志，或只查看错误。
- 「设置」可启用登录时后台启动、检查更新，并在需要时校验后直接编辑 `config.toml`。
- Susie 同时提供 Apple Silicon 和 Intel Mac 安装包；应用更新会自动选择当前 Mac 对应的版本。
